## On Functions and Code Complexity

[youtube](https://www.youtube.com/watch?v=5Nc68IdNKdg)

We're taught to write more functions, but more functions make a program harder to understand - explicit knowledge becomes implicit, so the programmer has to remember it: who calls this function, and what program state is required to run it. Code expresses constraints & relationships. Comments are "code that never runs" - they probably have bugs, because they're never tested.

## Game Development

[youtube](https://www.youtube.com/watch?v=YdSdvIRkkDY)

Little access to learning material early on - made copies of games instead of new ones. Games test programming extremely, so some concepts from university don't hold up. **Put in the hours - do it a lot.** Curiosity pulled him toward design; he ran a yearly workshop encouraging indie-style games, which helped refine his designs. Minimize everything that isn't the main idea.
